# CryptoLab
A Cryptography Learning & Analysis Toolkit.

## Modules

### Classical Cryptography
Learn the foundations of cryptography by exploring classical ciphers.

- **Caesar**: A substitution cipher that shifts letters by a fixed amount.
- **Atbash**: A substitution cipher that maps A to Z, B to Y, etc.
- **Vigenère**: A polyalphabetic substitution cipher.
- **Playfair**: A digraph substitution cipher using a 5x5 matrix.
- **Affine**: A combination of multiplicative and shift ciphers.
- **Rail Fence**: A transposition cipher writing text in a zigzag pattern.

### Features
For each cipher, you can:
1. **Encrypt** plaintext.
2. **Decrypt** ciphertext.
3. **Learn**: See step-by-step breakdowns of the encryption process and learn about strengths/weaknesses.
