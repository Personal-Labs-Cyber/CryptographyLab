Caesar Cipher Brute Force

Because the Caesar cipher only has 25 possible keys, an attacker can simply try them all until they find English text.

Security Lesson

Why is Caesar vulnerable?

The Keyspace (total number of possible keys) is incredibly small. There are only 26 letters in the alphabet, meaning there are only 25 possible shift combinations.

How the attack works:

  1. The computer decrypts the message using Shift 1, 2, 3... up to 25.
  2. It checks the resulting output against a dictionary of common English words (like "the", "and", "hello").
  3. The output with the highest "English score" is flagged as the likely plaintext!
Modern Cryptography Rule:

A secure algorithm must have a Keyspace so large that brute-forcing it would take supercomputers billions of years. (e.g., AES-256 has 2256 possible keys).
